## Unexpected findings and technical choices

Final review found that a raw-byte credential-echo check alone cannot detect a
JSON-escaped echo. New synthetic before/after regressions reproduced both a
catalogue projection and a Responses identity path. The broker now checks decoded
projected strings before provider-cache retention, and the Responses adapter
checks the decoded answer/accounting before settlement or journal retention.
Only obvious fixture values were used; no real credential, provider logging or
privacy condition was inspected or verified. Production Provider code is intact.

The final namespace review also found that the broker's unconditional `end(run)`
cleanup could reopen a replacement ledger after an earlier operation correctly
refused its changed identity. A before/after regression now checks the replacement's
actual run state, and cleanup uses the same ledger pin/permission guard. If that
guard fails, no cleanup transaction opens; the original run remains consumed
for later separately authorized inspection instead of silently touching new state.

The repository's existing RecurringStore declares rolling **weekly5cases/25GET/
5per-version**. The previously observed installed report used daily fields and
installed recurring code identity remains **UNKNOWN**. This change neither
renames those fields nor bridges them using titles, equal digests or report
counters. A real bridge requires the exact existing installed ledger, epoch,
code and material correspondence under separate access/live grants.

Research is a separate stage to preserve the existing two-call protocol. Its
own60s deadline and the unchanged60s model deadline give120s of aggregate stage
ceilings; this is not a claim that research fits inside the old model-stage
deadline or that a live host's cancellation behavior has been verified.

Shared cache reuse is deliberately conservative: only the same occurrence and
selected plan with a matching durable receipt may use it. Unbound/cross-case
cache evidence blocks rather than performing another GET to bypass history.
The source title is the only selected title variant in this slice. All test
counters/rates are explicit fixtures, not a new scoring policy or financial
authorization. The private journal supports one immutable selected simulated
budget per history; changing the ceiling/binding cannot create another budget.

The explicit installer verifies a frozen25-file source manifest and writes only
code into an existing empty private fixture destination. It is code-integrity
proof under the stable owning-account assumption, not an installer for a daemon,
host isolation, a live storage grant or a safe production deployment mechanism.
