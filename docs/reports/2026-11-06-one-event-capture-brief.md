# One-event collector capture brief

Implement the architect-approved default-disabled one-event capture in the
existing isolated collector. Preserve ordinary intake and every deployment,
provider, privacy and production gate. A private exact owner grant binds one
server-lifetime nonce, exact source/channel/filter and finite expiry. First
matching or exact external-ID selection must admit only the actual current
eligible unresolved/needs_review occurrence. Derive receipt identifiers inside
the same SQLite transaction; reserve durably before retaining bytes, release
only after commit, and never replace a failed or interrupted attempt. Lifetime
nonce and latch must fail closed across storage failure and restart. No new
service, permission, directory creation, provider or historical reconstruction.

Validate with invented Handler/SQLite fixtures, network tripwire, isolated
stdlib closure and exact-head supported CI. Independent reviewer and architect
verification precede delegated repository merge. Actual deployment, nonce
observation, private arm, source capture and API disclosure remain closed.
