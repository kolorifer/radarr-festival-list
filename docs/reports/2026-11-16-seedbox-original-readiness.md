# Local original-message readiness before source preparation

## Agreed scope and observed boundary

Main observed one current eligible case whose exact original actor record had a
payload and reference but lacked context, prepared text and a terminal result.
The actor job was pending, with zero message attempts and no lease. Two earlier
preparation attempts retain generic failures; their exact historical phase and
whether either acquired a source remain unknown. No model attempt or retained
evidence was observed. This is a local lifecycle prerequisite, not an identity
assessment failure. No source/key/provider/host operation belongs to this writer.

`actor_listing` already filters exact normalized metadata and `_target` binds the
release/version and original reference. No stale-job selection defect is established.
Invented different-version fixtures confirm the older metadata cannot shadow the
selected version. Multiple matching versions still refuse.

## Bounded correction

Before source preparation, the worker verifies the current selected collector
case and checks the exact local original. A missing job/message, incomplete
original or still-active original lifecycle waits without credentials, GETs,
provider reservations or a source-start marker. Invalid payloads/references,
ambiguous jobs, failed or consumed original edits remain refusals. The original
quiescence predicate is shared unchanged with the final delivery guard.

Waiting transitions bind case/version, configuration, selected actor database and
a digest of local prerequisite fields. Unchanged polls are quiet. Scheduling-only
`due` changes and increments of already-positive attempts do not create progress.
A clock alone cannot reopen an unchanged waiting record. Existing bounded worker
reconciliation detects local changes without new timers or producer changes.

The actual acquisition repeats the local check before its source-start marker
and before configuration/credentials/GET. A race retains the exact incomplete
observation that refused, then waits; it does not replace that observation with
a later read or spin. Interrupted attempts after the source marker remain unknown
and blocked. New source failures carry a finite local/acquisition phase and reason;
no arbitrary exception text, URLs or actor payloads enter diagnostics.

## Existing blocked preparation recovery

Old generic failures are never automatically relabelled as proven no-GET waits.
With the sole worker stopped, main may prepare
`seedbox_original_readiness.recovery_proposal(queue, config, preparation)` only
when the current exact original is complete and quiescent. The proposal binds the
configuration, current case/version/local original/target, complete queue history,
old failure and source-start hashes. It preserves the historical source outcome
as unknown and explicitly authorizes one new source observation, not a replayed
provider or sender. It refuses any related-case provider/sender/evidence/delivery
consumption, superseded preparation, prior recovery, existing evidence directory,
shared circuit, non-interruption source failure or exhausted source-attempt cap.

After independently reviewing that private exact proposal, main can invoke:

```
python -I -B BOOTSTRAP MANIFEST MANIFEST_SHA original-recover CONFIG CONFIG_SHA PREPARATION PROPOSAL_SHA
```

Existing actor/collector lifetimes, confinement and singleton apply. This command
performs local reads and appends one proof-bound recovery; it does not fetch,
read credentials, run a model or send. Current target/case must remain unchanged
when ordinary worker preparation resumes and again at the acquisition boundary.
Prior records and attempts remain intact. The one-use recovery atomically clears
only its selected local/source interruption block; ordinary source cooldowns,
budgets, freshness, no-duplicate and final sender checks still apply. A current
pending original is not eligible for this explicit recovery yet.
