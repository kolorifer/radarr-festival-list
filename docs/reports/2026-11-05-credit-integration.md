# Synthetic low-cost Responses integration

The dormant adapter now has an explicit fixed synthetic test entry point using
`gpt-5-nano-2025-08-07`. It accepts no movie input or model override. The existing
fixed HTTP implementation still refuses real activation unconditionally.

The parent binds the exact model, request, project, per-request History and a
separate selected shared credit History and its exact journal-file device/inode.
That journal must already exist; missing or replaced files refuse rather than
creating a fresh budget. It reserves one full cent before HTTP;
success, malformed output, timeout and unknown outcomes retain that debit. Five
reservations exhaust the five-cent envelope within the intact selected ledger. With the selected ledger intact, restart, changed request/run IDs or
new per-request histories do not reset that shared ledger. No refund, automatic
retry or model upgrade is implemented. Replacing/deleting a ledger is not a
supported reset. Uniquely enrolling one immutable real ledger across all parent
contexts remains an unresolved prerequisite at the closed live gate. Independently
re-pinned or caller-forged contexts cannot establish that authority. Same-inode
truncation or rollback to an earlier valid journal also requires an external
anti-rollback anchor before live use; the existing local hash chain does not
authenticate a missing suffix. This increment does not claim adversarial
anti-reset protection.

The Nano parser validates its cached-input/reasoning-output usage shape and exact
snapshot response identity separately from the existing Sol cache-write shape.
Output limits include reasoning tokens. Published standard input/output rates
are pinned at USD 0.05/0.40 per million tokens (cache read 0.005); the 65,536/4,096
token ceilings imply USD 0.0049152 before the conservative one-cent reservation.
The input ceiling still needs real processed-input coverage verification before
a live send; byte length is not a token count. Shutdown is December 11, 2026 UTC,
with no fallback. See the official [model page](https://developers.openai.com/api/docs/models/gpt-5-nano)
and [deprecations](https://developers.openai.com/api/docs/deprecations).

The existing external offline constructor prepares expanded historical requests;
it is not part of the installed runtime closure. The installed parent now accepts
those exact independently selected bytes without losing dated
catalogue observations, expiry labels or qualifications. The parent requires
exact selected disclosure bytes and a disclosure hash in privacy evidence;
captured-source authenticity, currentness and approvals stay false/unknown.
Pins establish correspondence, not authenticity of external evidence.

Validation: focused tests cover exact wire policy, usage and model mismatch,
retirement, changed pricing/ledger pins, five-cent exhaustion, timeout across
restart, unchanged expanded historical input and refusal at the real boundary.
Independent review and supported exact-head CI are required before merge; their
immutable results are recorded on the PR. No deployment or live API call occurred.

## Remaining external setup

Provide a dedicated API project in the organization that received the claimed
credits, with verified remaining credit/expiry and a verified no-cash spending
configuration, then provision its restricted project credential through the
secure operator route (never chat, repository or logs). Purchased-credit fallback,
auto recharge and competing credit consumption must be resolved, not assumed
safe from a project budget warning. The actual account evidence and processed
input coverage must be verified before a separately reviewed real authorizer can
open this boundary. See [credit behavior](https://developers.openai.com/api/docs/guides/chatgpt-api-credits).
Only the fixed synthetic request is proposed first; historical movie disclosure,
notifications and production model selection remain separate.
