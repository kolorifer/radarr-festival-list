# Append-only fifth synthetic opportunity

The existing manual continuation command accepts an explicit --slot5 for one
additional three-cent reservation, capped at twelve cents on the same ledger.
Its default remains slot4. The new grant requires the exact twelve-record prior
shape, including slot4's http_receive / responses_network_completion_unknown /
network_outcome_unknown diagnostic and the three retained three-cent debits.
The extension binds prior evidence, journal prefix, prior attempt hashes,
original enrollment, storage identities and the fixed fifth synthetic request.
It appends before creating the new attempt directory, so interrupted grants are
terminal. Original slots, ledgers, defaults and model/request policy are retained.

Only an active held-root session carrying this exact grant can reserve the
additional three cents. The ordinary five-cent default is unchanged. Duplicate
extensions, consumed opportunities, malformed history, changed evidence/project,
insufficient credit, interrupted grants and slot6 refuse. The command itself
never prompts or calls HTTP. Invalid secret input still consumes no opportunity.
The accepted120s absolute observation path is reused without modification.

Seven new offline tests cover conservation/default ceiling, successful bound
receipt, replay/sixth-slot refusal, invalid input, interrupted grant, changed
prior history/evidence, the terminal diagnostic and a genuine installed module.
The installed command uses dummy input and the real fixed HTTP framing/parser
with invented socket I/O. A simulated30s header delay reaches the parser under
the existing120s allowance, rather than the old25s cutoff.

Initial local run: five passed, one setup stopped at the existing
supervised_evidence_changed guard, and one malformed-history test incorrectly
mocked a read path outside the transaction. The fixture was corrected to build
the malformed diagnostic through the ordinary journal path. Its subsequent
focused check also stopped in earlier fixture renewal at evidence_changed.
The combined check ran63 tests:61 passed; that new setup error and one existing
reauthorization fixture failure both reported evidence_changed. These failures
remain recorded; no guard was changed or bypassed and no cause is assumed.
Independent review and supported exact-head full CI are required before merge.

No actual pilot state, evidence, credential, account or provider was accessed.
Distinct private runtime preparation and offline rehearsal follow acceptance;
actual extension and manual execution remain separate actions. The unrelated
active cleanup task, production services and automatic operation are unchanged.
