runtime assessment leaves the Codex effective tool/context boundary unproved;
Task4 explicitly authorizes this separate offline HTTP route. Public official
Responses fields include cache-write usage and default opaque encrypted
reasoning metadata. They are handled without retaining reasoning. A fake that
accepts different fields would not establish compatibility.

reads in one finite deadline, refusing existing timer ownership or unsupported
thread/platform state. This technical constraint avoids a timeout that applies

input or environment. These are tested mechanisms, not an attestation about a
future host's mandatory network/security policy.
