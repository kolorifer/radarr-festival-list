# Historical research snapshots

These snapshots preserve the source trees of research PRs #1–#5 for review;
they are historical, isolated from current production modules, and do not
select a qualification threshold or activate a workflow. Nested workflows are
archival files and are not GitHub Actions workflows at the repository root.

- `historical-handoff-snapshot/` preserves the files changed by #1 at its head
  `7e9c32f7ac5d8c9a310e69a706731a272f23c003`.
- `historical-pr-2/`, `historical-pr-3/` and `historical-pr-4/` preserve each
  PR's added or changed files at its own head, including earlier data versions.
  These are partial snapshots intended to accompany the complete later tree.
- `historical-qualification-snapshot/` preserves the complete #5 head
  `906ff64bccd5b7ea61d36b03defa09c9363617de`, including the prior research
  stack and its frozen inputs, generated artifacts, tests, reports and code.

The original branches and PRs provide deletion history and context. Earlier
instructions, task files, deployment claims and decisions inside snapshots are
historical evidence, not current assignments or authorization. Scripts may
perform network requests when explicitly invoked; adding the files schedules
nothing. Research-only thresholds are not adopted production policy.
